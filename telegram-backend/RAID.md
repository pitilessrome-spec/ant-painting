# RAID V0.1 candidate
Default off: ANT_RAID_ENABLED=1 only in a dedicated acceptance environment after migration and authenticated tests. Never enable on production before QA. The 8×8 color-dispatch board is a separate server-authoritative prototype, not the full 3D main puzzle. No ad buffs, no real colony bonuses yet. Team caps 2/3/8, all solo allowed, 4 bosses; room mutations serialized in PostgreSQL, per-member sequences reject duplicate damage and invalid inputs. First unique roster rankings (overall by boss+tier), top-ten world announcements returned for 24h and repeated three times per device, one reward ledger row per player/boss/tier/season. Rewards are records, not yet inventory items. Reconnect uses room ID or invite code. Snapshot polling, not WebSocket. Need live two-user and concurrent PostgreSQL testing, app UI QA, full independent main-board adaptation, anti-bot/rate load testing, season administration, separate ranked assistance verification, inventory and cross-platform identity. No fake data, no unauthenticated sessions.
