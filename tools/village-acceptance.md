# Village build and local time acceptance
- Select an empty plot; choose an affordable building; the confirmation above the catalog shows price and Build. A purchase requires explicit confirmation.
- 5 wood and 2 petals: flower costs 2/1; after one construction 3/1 remain. Mushroom needs 5/3; do not deduct on failure. An occupied plot cannot be bought again.
- Day is 06:00 through 17:59 local device time; night is 18:00 through 05:59. Refresh automatically every 15 seconds and on return to the app. The label shows current state, not a manual switch.
- Local save key and game rewards unchanged.
