# 蚂蚁画布 微信小游戏 V0.7 中文测试版

直接导入本目录，项目类型选小游戏。先运行 `node wechat-game/build.mjs`（仓库源码才需要；测试压缩包已生成 core.js、village-core.js 与 maps）。使用小游戏 AppID 替换 touristappid；游客模式只可本地体验，无法上传。保留正式 V7 搬画核心和道具规则、四大原地图、领地建设、蚁后与仓库、孵化、工蚁分工、地区活动、产业基础。副本/组队 BOSS 入口与代码暂不打包；原主线守护者保留。Canvas 界面为原生移植，不宣称与网页完全相同。微信广告位默认关闭，后续配置真实激励广告 ID。当前本地游客存档；微信登录、排行榜、云存档、完整产业运输及原网页全部交互未接入。
